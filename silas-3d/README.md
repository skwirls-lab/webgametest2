# Silas — 3D character kit

A rigged 3D Silas, generated by code, drawn in the clip's comic style. Open
**`silas-turnaround.html`** in a desktop browser: it sculpts him in a few seconds, shows the model
sheet, then a live viewer. Drag to rotate; the buttons underneath pose him, change the lighting and
switch the azure eyes on.

Finished sheets are in `sheets/` (model sheet, 12-angle turnaround, grey sheet, poses, style tests
and side-by-side comparisons with the reference art). `STATUS.md` is the build log, pass by pass,
including the independent reviews. `PLAN.md` is the plan this was built to.

## How he is made

| step | where | what |
| --- | --- | --- |
| Reference data | `tools/seg.py`, `prep.py`, `export.py` -> `src/refdata.js` | The reference sheet's front, side and back figures are cut out, labelled part by part, and turned into outlines, distance fields, and a layer of traced interior line strokes. |
| Form | `src/sdf.js`, `src/fit.js`, `src/model.js` | Every part is sculpted from blended volumes and then stretched or trimmed until its front and side outlines sit on the reference's. |
| Look | `src/look.js` | Three passes: flat colours with crisp markings, banded light and halftone; a buffer of normals, part ids and depth; then an ink line wherever parts meet, depth breaks or the surface creases. Lighting presets and the printed-comic pass live here too. |
| Rig | `src/rig.js` | Skeleton, automatic skin weights, pose library, tail and cloak sway. |
| Character | `src/silas.js` | Builds the character and exposes the control API. |
| Page and harness | `src/app.js`, `tools/check.cjs`, `tools/score.py` | Model sheet, viewer, and the one-command scoring harness. |

The only library is three.js (MIT, in `vendor/`), inlined by `node build.cjs`. No generative AI,
modelling apps or downloaded assets. The reference images in `reference/` are used for
measurement, outlines, palette and the traced line strokes; none of their painted shading is used.

## Using Silas in a shot

```js
const silas = await buildSilas();          // THREE.Group
scene.add(silas);
const api = silas.userData.api;
api.pose('sprint', phase);                 // or 'stand', 'crossed', 'daggers', 'leap', 'allFours', 'skid', 'brace', 'flame', or {bone: [rx, ry, rz]}
api.sway(timeSeconds, speed);              // tail and cloak follow-through; call after pose()
api.state('azure', amount);                // glowing eyes and spreading veins; 'normal' to reset
const background = api.look('moon');       // 'sheet', 'grey', 'moon', 'violet', 'azure'
new InkPipeline(renderer).render(scene, camera, background, lineScale);
```

Pose him at 12 steps a second for the "on twos" feel and move the camera every frame.

## Checking the model against the reference

```bash
pip install opencv-python-headless && npm i playwright && npx playwright install chromium   # once
python3 tools/seg.py reference/sheet-turnaround.jpg build/ref      # only if the reference changes
PYTHONPATH=tools python3 tools/prep.py && PYTHONPATH=tools python3 tools/export.py
node tools/check.cjs final final      # scores silhouettes and parts, renders every sheet into reports/final/
```
