# Silas — 3D character kit (step 1: turnaround)

Open `silas-turnaround.html` in a desktop browser. It sculpts Silas in a few seconds, shows a
four-view model sheet, and gives a drag-to-rotate viewer underneath.

Everything is generated by code at load time: the model is sculpted from blended volumes
(`src/model.js`) and meshed with a small surface-nets mesher (`src/sdf.js`); the graphic-novel
shading (banded light, halftone, spotted blacks, rim lights, inked outlines) is in `src/toon.js`.
The only library is three.js (MIT, `vendor/`), inlined into the page by `node build.cjs`.
No images, downloaded models or generative AI are used; the reference sheets were used only to
measure proportions.
